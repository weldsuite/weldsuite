# VAT returns

Periodic VAT / sales-tax filing records. Mutations require the `vat_returns:write` scope; reads require `vat_returns:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Accounting entity scoping

Every VAT return belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity.
- **On create:** send `entityId` in the JSON body. The external API does **not** pick a default for you. Read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## The VAT return model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `vat_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="periodStart" type="string">Filing period start.</Property>
  <Property name="periodEnd" type="string">Filing period end.</Property>
  <Property name="status" type="string">Draft, submitted, etc.</Property>
  <Property name="totalVat" type="string">Net VAT due (decimal string).</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## List vat returns {{ tag: 'GET', label: '/v1/vat-returns' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/vat-returns">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/vat-returns \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "vat_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create a VAT return {{ tag: 'POST', label: '/v1/vat-returns' }}

<Row>
  <Col>

    Create a VAT return.
    
    ### Accounting entity
    
    Include **`entityId`** (an `ent_*` id). The external API does not infer a default — resolve it from [accounting settings](/accounting-settings) (`defaultEntityId`) or [accounting entities](/accounting-entities) (`isDefault`).
    
    Optional: `entityId`, `periodStart`, `periodEnd`, `jurisdiction`, totals. Calculate, file, and XML endpoints are on the app API.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/vat-returns">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/vat-returns \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "periodStart": "2024-10-01",
        "periodEnd": "2024-12-31"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "vat_new456",
        "entityId": "ent_abc123",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Retrieve a VAT return {{ tag: 'GET', label: '/v1/vat-returns/:id' }}

<Row>
  <Col>

    Retrieve a single VAT return by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/vat-returns/vat_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/vat-returns/vat_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "vat_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>
