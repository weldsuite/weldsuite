# Campaigns

A campaign is a sequence of up to 10 emails (steps) that WeldReach sends to each enrolled prospect from the campaign's mailboxes, on the campaign's days and inside its sending window. Reads require the `reach_campaigns:read` scope; every change, including launching, pausing and enrolling prospects, requires `reach_campaigns:write`. {{ className: 'lead' }}

<ResourceVersionBanner />

<Note>
  WeldReach is available on request only. Until WeldSuite approves the workspace, every endpoint here returns `403 APP_ACCESS_REQUIRED`. See the [WeldReach overview](/weldreach).
</Note>

## The campaign model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `rcmp_abc123`).</Property>
  <Property name="name" type="string">Campaign name, up to 200 characters.</Property>
  <Property name="status" type="string">One of `draft`, `active`, `paused`, `completed`, `archived`. See [the lifecycle](#lifecycle).</Property>
  <Property name="timezone" type="string">IANA timezone the sending window is read in (e.g. `Europe/Amsterdam`).</Property>
  <Property name="sendDays" type="integer[]">ISO weekdays the campaign sends on, `1` (Monday) to `7` (Sunday).</Property>
  <Property name="windowStart" type="string">Start of the daily sending window, `HH:MM`.</Property>
  <Property name="windowEnd" type="string">End of the daily sending window, `HH:MM`. Must be after `windowStart`.</Property>
  <Property name="dailyLimit" type="integer">Most emails this campaign sends per day, 1 to 10,000. The mailbox caps and the workspace's `maxDailySends` still apply.</Property>
  <Property name="minGapMinutes" type="integer">Minimum minutes between two sends from the same mailbox, 1 to 240.</Property>
  <Property name="stopOnAutoReply" type="boolean">Stop a prospect's sequence when an auto-reply (such as an out-of-office) comes back.</Property>
  <Property name="stats" type="object">Running totals: `prospects`, `sent`, `replied`, `interested`, `bounced`, `unsubscribed`.</Property>
  <Property name="pausedReason" type="string">Why the campaign is paused, or `null`. `manual` when a person or an API call paused it; `bounce_rate` when WeldReach paused it because more than 3% of its recent sends bounced.</Property>
  <Property name="launchedAt" type="timestamp">When the campaign was first launched, or `null`.</Property>
  <Property name="completedAt" type="timestamp">When every enrollment finished, or `null`.</Property>
  <Property name="ownerId" type="string">User ID of the campaign's owner, or `null`.</Property>
  <Property name="createdAt" type="timestamp">When the campaign was created.</Property>
  <Property name="updatedAt" type="timestamp">When the campaign was last updated.</Property>
</Properties>

Retrieving a single campaign also returns:

<Properties>
  <Property name="steps" type="object[]">The emails, in order. See [the step model](#the-step-model).</Property>
  <Property name="mailboxIds" type="string[]">The [mailboxes](/reach-mailboxes) the campaign sends from.</Property>
</Properties>

### The step model {{ id: 'the-step-model' }}

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `rstp_abc123`).</Property>
  <Property name="order" type="integer">Position in the sequence, starting at `0`.</Property>
  <Property name="delayDays" type="integer">Days to wait after the previous step was sent, 0 to 90. Not used for the first step.</Property>
  <Property name="delayHours" type="integer">Extra hours to wait, 0 to 23.</Property>
  <Property name="subject" type="string">Subject, up to 300 characters. Supports [template variables](/weldreach#template-variables).</Property>
  <Property name="body" type="string">Plain-text body, up to 20,000 characters. Supports template variables. The workspace's sender address and opt-out text are added below it.</Property>
  <Property name="replyInThread" type="boolean">Send this follow-up as a reply in the same email thread instead of a new email.</Property>
</Properties>

A due step that falls outside the sending window waits for the next window.

### Lifecycle {{ id: 'lifecycle' }}

| From | Action | To |
|------|--------|----|
| `draft` or `completed` | [Launch](#launch-a-campaign) | `active` |
| `active` | [Pause](#pause-a-campaign), or WeldReach pauses it automatically | `paused` |
| `paused` | [Resume](#resume-a-campaign) | `active` |
| `active` | Every enrollment finished | `completed` |

A state change that does not fit this table returns `409` with one of these codes:

| `code` | Meaning |
|--------|---------|
| `CAMPAIGN_ACTIVE` | The campaign is running. Pause it before you delete it or change its steps, or it was already launched. |
| `CAMPAIGN_PAUSED` | The campaign is paused; resume it instead of launching it. |
| `CAMPAIGN_NOT_ACTIVE` | Only a running campaign can be paused. |
| `CAMPAIGN_NOT_PAUSED` | Only a paused campaign can be resumed. |
| `CAMPAIGN_CLOSED` | The campaign is completed or archived, so it takes no new prospects (or it is archived and cannot launch). |

## Enroll prospects {{ tag: 'POST', label: '/v1/reach/campaigns/:id/prospects' }}

<Row>
  <Col>

    Add prospects to the campaign, by id, by [list](/reach-lists), or both. In a `draft` or `paused` campaign they wait as `queued`; in an `active` campaign they start right away. A completed or archived campaign returns `409 CAMPAIGN_CLOSED`, and an unknown `listId` returns `404`.

    Prospects that cannot be emailed are skipped and counted by reason:

    | Reason | Why |
    |--------|-----|
    | `already_enrolled` | Already in this campaign. |
    | `suppressed` | The address or its domain is on the [suppression list](/reach-suppressions). |
    | `consumer` | A free-mail address, and the workspace may only email businesses. |
    | `invalid` | The prospect's `validation` is `invalid`, `role` or `no_mx`. |
    | `enrolled_elsewhere` | Queued or active in another campaign. A prospect is in one running sequence at a time. |

    ### Attributes

    <Properties>
      <Property name="prospectIds" type="string[]">Up to 10,000 [prospect](/reach-prospects) ids.</Property>
      <Property name="listId" type="string">A prospect list; all its members are enrolled.</Property>
    </Properties>

    Give `prospectIds`, `listId` or both.

    ### Response

    <Properties>
      <Property name="added" type="integer">Prospects enrolled.</Property>
      <Property name="skipped" type="object[]">`{ reason, count }` for every reason above that applied.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/reach/campaigns/rcmp_abc123/prospects">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/reach/campaigns/rcmp_abc123/prospects \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{ "listId": "rpl_abc123" }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "added": 231,
        "skipped": [
          { "reason": "suppressed", "count": 4 },
          { "reason": "enrolled_elsewhere", "count": 5 }
        ]
      }
    }
    ```

  </Col>
</Row>

## Launch a campaign {{ tag: 'POST', label: '/v1/reach/campaigns/:id/launch' }}

<Row>
  <Col>

    Start sending. Queued prospects become active and are spread over the next sending window. Works from `draft` and `completed`; see [the lifecycle](#lifecycle) for the `409` codes. Returns the campaign.

    A campaign that is not ready returns `400` with every problem in `details.problems`:

    | Problem | Fix |
    |---------|-----|
    | `no_steps` | [Add steps](#replace-the-steps). |
    | `no_active_mailbox` | [Assign](#set-the-mailboxes) at least one mailbox with status `active`. Mailboxes that are still warming up do not count. |
    | `no_sender_identity` | Fill in the sender company name and postal address in the WeldReach settings. Every email carries them. |
    | `no_prospects` | [Enroll prospects](#enroll-prospects). |

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/reach/campaigns/rcmp_abc123/launch">

    ```bash {{ title: 'cURL' }}
    curl -X POST https://api.weldsuite.org/v1/reach/campaigns/rcmp_abc123/launch \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: '400 Not ready' }}
    {
      "error": {
        "code": "BAD_REQUEST",
        "message": "This campaign cannot be launched yet",
        "details": { "problems": ["no_active_mailbox", "no_prospects"] }
      }
    }
    ```

  </Col>
</Row>
