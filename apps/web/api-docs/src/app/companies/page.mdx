# Companies

Companies are the organizations in your CRM, customers, suppliers, and prospects. This page covers the company model and its endpoints. Mutations require the `companies:write` scope; reads require `companies:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

<Note>
  A company is created or updated in **one request**: every standard field and every [custom field](#custom-fields) goes in the same JSON body. There is no need to create the company first and then set its fields one call at a time.
</Note>

---

## Custom fields {{ id: 'custom-fields' }}

Custom fields are the fields your workspace adds to companies in WeldCRM (Settings → Custom fields). In the API they travel in the `customFields` object of the company, keyed by the field's **slug**, next to the standard fields:

```json
{
  "name": "Doe Manufacturing BV",
  "customFields": {
    "contract_tier": "gold",
    "seats": 25,
    "renewal_date": "2027-01-31"
  }
}
```

- **Slugs.** [List custom fields](#list-custom-fields) returns every slug with its type and, for select fields, its options.
- **Values.** A value must suit its field: a number for `number`, `currency` and `rating` fields (`"25"` is accepted and stored as `25`), an ISO 8601 date for `date`, one of the field's option values for `single_select`, an array of option values for `multi_select`, `true`/`false` for `boolean`, and text for the rest. Responses return the stored value (`25`, `"2027-01-31T00:00:00.000Z"`).
- **Checked before anything is written.** When a value doesn't suit its field, the request fails with `400` and nothing is saved. Every refused value is listed at once, so one corrected retry is enough:

  ```json
  {
    "error": {
      "code": "BAD_REQUEST",
      "message": "Invalid custom field values: 'bronze' is not a valid option for 'contract_tier'; 'seats' must be a number",
      "details": {
        "field": "customFields",
        "errors": {
          "contract_tier": "'bronze' is not a valid option for 'contract_tier'",
          "seats": "'seats' must be a number"
        }
      }
    }
  }
  ```

- **Clearing.** `null` (or `""`) clears a field.
- **Updates merge.** On `PATCH`, only the slugs you send change; the company's other custom fields keep their values.
- **Unknown keys.** A key that is not one of the workspace's slugs is kept on the record and returned by the API, but WeldCRM doesn't show it. Check the slug if a value doesn't appear in the app.
- Required custom fields are not enforced on API writes.

## List companies {{ tag: 'GET', label: '/v1/companies' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list of companies.

    ### Optional query parameters

    <Properties>
      <Property name="limit" type="integer">
        Items per page (max 100).
      </Property>
      <Property name="cursor" type="string">
        Pagination cursor from the previous response.
      </Property>
      <Property name="search" type="string">
        Search across display name, name, trading name, email, and VAT number.
      </Property>
      <Property name="status" type="string">
        Filter by status.
      </Property>
      <Property name="ownerId" type="string">
        Filter by owner.
      </Property>
      <Property name="industry" type="string">
        Filter by industry.
      </Property>
      <Property name="isSupplier" type="boolean">
        Filter by supplier flag.
      </Property>
      <Property name="isLead" type="boolean">
        Filter by lead flag.
      </Property>
      <Property name="listId" type="string">
        Restrict to members of a company list.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/companies">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/companies \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d isSupplier=true
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        {
          "id": "company_abc123",
          "name": "Smith Industries BV",
          "displayName": "Smith Industries",
          "industry": "Manufacturing",
          "email": "info@smith.example",
          "isSupplier": true,
          "status": "customer",
          "customFields": { "contract_tier": "silver" }
        }
      ],
      "pagination": { "totalCount": 58, "hasMore": true, "cursor": "company_abc123" }
    }
    ```

  </Col>
</Row>

## List custom fields {{ tag: 'GET', label: '/v1/companies/custom-fields', id: 'list-custom-fields' }}

<Row>
  <Col>

    The workspace's company custom fields, in the order WeldCRM shows them. Use the `slug` of each as its key in `customFields`.

    ### Fields

    <Properties>
      <Property name="slug" type="string">
        The key to use in `customFields`.
      </Property>
      <Property name="name" type="string">
        The label shown in WeldCRM.
      </Property>
      <Property name="fieldType" type="string">
        One of `text`, `textarea`, `number`, `currency`, `rating`, `date`, `boolean`, `single_select`, `multi_select`, `url`, `email`, `phone`, `file`, `user_ref`, `entity_ref`.
      </Property>
      <Property name="options" type="array">
        For select fields, the allowed values (`{ label, value }`). Send the `value`.
      </Property>
      <Property name="required" type="boolean">
        Required in WeldCRM's forms (not enforced on API writes).
      </Property>
      <Property name="description" type="string">
        Help text.
      </Property>
      <Property name="group" type="string">
        The group the field is shown in.
      </Property>
      <Property name="config" type="object">
        Type-specific settings (e.g. a currency field's currency).
      </Property>
    </Properties>

## Create a company {{ tag: 'POST', label: '/v1/companies' }}

<Row>
  <Col>

    Create a company with all its fields, custom fields included, in one request. `displayName` is derived automatically from `tradingName`/`name`. Custom field values are checked before anything is written: when one is refused, the request fails with `400` and no company is created.

    ### Required attributes

    <Properties>
      <Property name="name" type="string">
        Company name.
      </Property>
    </Properties>

    ### Optional attributes

    Every other field of [the company model](#the-company-model) except `id`, `displayName`, `createdAt` and `updatedAt`, among them:

    <Properties>
      <Property name="tradingName" type="string">Trading name.</Property>
      <Property name="registrationNumber" type="string">Registration number.</Property>
      <Property name="vatNumber" type="string">VAT number.</Property>
      <Property name="industry" type="string">Industry.</Property>
      <Property name="employeeCount" type="string">Number or range.</Property>
      <Property name="website" type="string">Website URL or domain.</Property>
      <Property name="email" type="string">Primary email.</Property>
      <Property name="phone" type="string">Primary phone.</Property>
      <Property name="primaryAddress" type="object">Primary address object.</Property>
      <Property name="ownerId" type="string">Owner user ID.</Property>
      <Property name="status" type="string">Status. Defaults to `prospect`.</Property>
      <Property name="lifecycleStage" type="string">Lifecycle stage.</Property>
      <Property name="isSupplier" type="boolean">Supplier flag.</Property>
      <Property name="isLead" type="boolean">Lead flag.</Property>
      <Property name="tags" type="array">Tags.</Property>
      <Property name="customFields" type="object">Custom field values by slug. See [Custom fields](#custom-fields).</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/companies">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/companies \
      -H "Authorization: Bearer wsk_your_api_key" \

        "tradingName": "Doe Manufacturing",
        "registrationNumber": "12345678",
        "vatNumber": "NL123456789B01",
        "industry": "Welding",
        "employeeCount": "51-200",
        "website": "doe.example",
        "email": "info@doe.example",
        "phone": "+31 20 123 4567",
        "primaryAddress": {
          "line1": "Kade 1",
          "postalCode": "1011 AB",
          "city": "Amsterdam",
          "country": "NL"
        },
        "status": "customer",
        "lifecycleStage": "customer",
        "segment": "mid-market",
        "source": "erp-sync",
        "isSupplier": true,
        "preferredLanguage": "nl",
        "timezone": "Europe/Amsterdam",
        "tags": ["erp", "priority"],
        "notes": "Imported from the ERP",
        "customFields": {
          "contract_tier": "gold",
          "seats": 25,
          "renewal_date": "2027-01-31",
          "erp_id": "ERP-1001"
        }
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "company_new456",
        "name": "Doe Manufacturing BV",
        "tradingName": "Doe Manufacturing",
        "displayName": "Doe Manufacturing",
        "vatNumber": "NL123456789B01",
        "industry": "Welding",
    ```

## Update a company {{ tag: 'PATCH', label: '/v1/companies/:id' }}

<Row>
  <Col>

    Partially update a company. Only the fields you send are changed, and any number of them can go in one request. In `customFields`, only the slugs you send change; send `null` to clear one.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="PATCH" label="/v1/companies/company_abc123">

    ```bash {{ title: 'cURL' }}
    curl -X PATCH https://api.weldsuite.org/v1/companies/company_abc123 \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "status": "customer",
        "industry": "Heavy Manufacturing",
        "customFields": { "seats": 30, "erp_id": null }
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "company_abc123",
        "status": "customer",
        "industry": "Heavy Manufacturing",
        "customFields": { "contract_tier": "silver", "seats": 30 },
        "updatedAt": "2026-11-05T15:00:00Z"
      }
    }
    ```

  </Col>
</Row>
