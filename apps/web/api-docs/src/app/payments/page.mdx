# Payments

Payments applied to invoices or bills. Mutations require the `payments:write` scope; reads require `payments:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## The payment model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `pay_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="amount" type="string">Payment amount (decimal string).</Property>
  <Property name="currency" type="string">Payment currency.</Property>
  <Property name="direction" type="string">`inbound` or `outbound`.</Property>
  <Property name="invoiceId" type="string">Linked invoice (if any).</Property>
  <Property name="billId" type="string">Linked bill (if any).</Property>
  <Property name="paymentDate" type="string">Date of payment.</Property>
  <Property name="status" type="string">Payment status.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## List payments {{ tag: 'GET', label: '/v1/payments' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. Optional query parameters: `limit`, `cursor`, `entityId`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/payments">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/payments \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
      "data": [
        { "id": "pay_abc123" }

    }
    ```

  </Col>
</Row>

## Create a payment {{ tag: 'POST', label: '/v1/payments' }}

<Row>
  <Col>

    Create a payment.
    
    ### Required attributes
    
    <Properties>
      <Property name="amount" type="string | number">Payment amount.</Property>
    </Properties>
    
    Optional: `entityId`, `direction`, `invoiceId`, `billId`, `bankAccountId`, `currency`, `paymentDate`, `method`, `reference`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/payments">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/payments \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "amount": "1250.00",
        "currency": "EUR",
        "direction": "inbound"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "pay_new456",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>
