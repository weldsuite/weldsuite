# Payments

Payments applied to invoices or bills. Mutations require the `payments:write` scope; reads require `payments:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Accounting entity scoping

Every payment belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity.
- **On create:** send `entityId` in the JSON body. The external API does **not** pick a default for you. Read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## The payment model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `pay_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="amount" type="string">Payment amount (decimal string).</Property>
  <Property name="currency" type="string">Payment currency.</Property>
  <Property name="direction" type="string">`inbound` or `outbound`.</Property>
  <Property name="invoiceId" type="string">Linked invoice (if any).</Property>
  <Property name="billId" type="string">Linked bill (if any).</Property>
  <Property name="paymentDate" type="string">Date of payment.</Property>
  <Property name="status" type="string">Payment status.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## List payments {{ tag: 'GET', label: '/v1/payments' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/payments">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/payments \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "pay_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create a payment {{ tag: 'POST', label: '/v1/payments' }}

<Row>
  <Col>

    Create a payment.
    
    ### Accounting entity
    
    Include **`entityId`** (an `ent_*` id). The external API does not infer a default — resolve it from [accounting settings](/accounting-settings) (`defaultEntityId`) or [accounting entities](/accounting-entities) (`isDefault`).
    
    ### Required attributes
    
    <Properties>
      <Property name="amount" type="string | number">Payment amount.</Property>
    </Properties>
    
    Optional: `entityId`, `direction`, `invoiceId`, `billId`, `bankAccountId`, `currency`, `paymentDate`, `method`, `reference`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/payments">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/payments \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "amount": "1250.00",
        "currency": "EUR",
        "direction": "inbound"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "pay_new456",
        "entityId": "ent_abc123",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Retrieve a payment {{ tag: 'GET', label: '/v1/payments/:id' }}

<Row>
  <Col>

    Retrieve a single payment by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/payments/pay_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/payments/pay_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "pay_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>

## Update a payment {{ tag: 'PATCH', label: '/v1/payments/:id' }}

<Row>
  <Col>

    Partially update a payment. Only the fields you send are changed. You may update `entityId` to move a record to another accounting entity when your workflow allows it.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="PATCH" label="/v1/payments/pay_abc123">

    ```bash {{ title: 'cURL' }}
    curl -X PATCH https://api.weldsuite.org/v1/payments/pay_abc123 \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{}'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "pay_abc123",
        "updatedAt": "2024-12-01T15:00:00Z"
      }
    }
    ```

  </Col>
</Row>
