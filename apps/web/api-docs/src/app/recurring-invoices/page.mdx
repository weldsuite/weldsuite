# Recurring invoices

Scheduled invoice templates. Mutations require the `recurring_invoices:write` scope; reads require `recurring_invoices:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Accounting entity scoping

Every recurring invoice belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity.
- **On create:** send `entityId` in the JSON body. The external API does **not** pick a default for you. Read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## List recurring invoices {{ tag: 'GET', label: '/v1/recurring-invoices' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/recurring-invoices">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/recurring-invoices \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "ri_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create a recurring invoice {{ tag: 'POST', label: '/v1/recurring-invoices' }}

<Row>
  <Col>

    Create a recurring invoice.
    
    ### Accounting entity
    
    Include **`entityId`** (an `ent_*` id). The external API does not infer a default — resolve it from [accounting settings](/accounting-settings) (`defaultEntityId`) or [accounting entities](/accounting-entities) (`isDefault`).
    
    Optional: `entityId`, `contactId`, `frequency`, `currency`, template line items. Generate and pause actions are on the app API.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/recurring-invoices">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/recurring-invoices \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "contactId": "acn_abc123",
        "frequency": "monthly"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "ri_new456",
        "entityId": "ent_abc123",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Retrieve a recurring invoice {{ tag: 'GET', label: '/v1/recurring-invoices/:id' }}

<Row>
  <Col>

    Retrieve a single recurring invoice by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/recurring-invoices/ri_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/recurring-invoices/ri_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "ri_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>

## Update a recurring invoice {{ tag: 'PATCH', label: '/v1/recurring-invoices/:id' }}

<Row>
  <Col>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="PATCH" label="/v1/recurring-invoices/ri_abc123">

    ```bash {{ title: 'cURL' }}
    curl -X PATCH https://api.weldsuite.org/v1/recurring-invoices/ri_abc123 \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{}'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "ri_abc123",
        "updatedAt": "2024-12-01T15:00:00Z"
      }
    }
    ```

  </Col>
</Row>
