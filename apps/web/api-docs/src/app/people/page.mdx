# People

People are the individual contacts in your CRM. This page covers the person model and its endpoints. Mutations require the `people:write` scope; reads require `people:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

<Note>
  A person is created or updated in **one request**: every standard field, every [custom field](#custom-fields) and the companies they work for go in the same JSON body.
</Note>

## Custom fields {{ id: 'custom-fields' }}

Custom fields on people work exactly as [on companies](/companies#custom-fields): they travel in `customFields`, keyed by slug, in the same body as the standard fields.

- [List custom fields](#list-custom-fields) returns the slugs, types and select options.
- Values are checked against their field before anything is written. A refused value fails the request with `400`, nothing is saved, and `error.details.errors` lists every refused value by slug.
- `null` (or `""`) clears a field. On `PATCH`, only the slugs you send change.
- A key that is not one of the workspace's slugs is kept and returned by the API, but WeldCRM doesn't show it.

## List people {{ tag: 'GET', label: '/v1/people' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list of people.

    ### Optional query parameters

    <Properties>
      <Property name="limit" type="integer">Items per page (max 100).</Property>
      <Property name="cursor" type="string">Pagination cursor.</Property>
      <Property name="search" type="string">Search across display name, full name, first/last name, and email.</Property>
      <Property name="status" type="string">Filter by status.</Property>
      <Property name="ownerId" type="string">Filter by owner.</Property>
      <Property name="isSupplier" type="boolean">Filter by supplier flag.</Property>
      <Property name="isLead" type="boolean">Filter by lead flag.</Property>
      <Property name="companyId" type="string">Filter to current employees of a company.</Property>
      <Property name="listId" type="string">Restrict to members of a people list.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/people">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/people \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d search=jane
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        {
          "id": "person_abc123",
          "firstName": "Jane",
          "lastName": "Doe",
          "fullName": "Jane Doe",
          "displayName": "Jane Doe",
          "email": "jane@doe.example",
          "title": "Operations Director",
          "customFields": { "shirt_size": "m" }
        }
      ],
      "pagination": { "totalCount": 12, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create a person {{ tag: 'POST', label: '/v1/people' }}

<Row>
  <Col>

    Create a person with all their fields, custom fields and companies in one request. `fullName` and `displayName` are derived when omitted. Custom field values and company IDs are checked before anything is written: when one is refused, the request fails with `400` and no person is created.

    ### Optional attributes

    Every field of [the person model](#the-person-model) except `id`, `displayName`, `createdAt` and `updatedAt`, plus:

    <Properties>
      <Property name="companyIds" type="array">
        IDs of the companies the person works for. Each becomes a current employment, so the person shows up under the company in WeldCRM and in `GET /v1/people?companyId=…`. An ID that names no company fails the request with `400` (`details: { field: "companyIds", missing: [...] }`).
      </Property>
      <Property name="primaryCompanyId" type="string">
        The person's main company. Linked even when it is not in `companyIds`.
      </Property>
      <Property name="customFields" type="object">
        Custom field values by slug. See [Custom fields](#custom-fields).
      </Property>
      <Property name="dateOfBirth" type="string">
        ISO 8601 date-time.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/people">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/people \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "firstName": "Jane",
        "lastName": "Doe",
        "email": "jane@doe.example",
        "title": "Operations Director",
        "department": "Operations",
        "directPhone": "+31 20 123 4567",
        "mobilePhone": "+31 6 1234 5678",
        "linkedinUrl": "linkedin.com/in/janedoe",
        "status": "active",
        "lifecycleStage": "customer",
        "isDecisionMaker": true,
        "preferredLanguage": "nl",
        "tags": ["erp"],
        "companyIds": ["company_new456"],
        "primaryCompanyId": "company_new456",
        "customFields": {
          "shirt_size": "m",
          "nps": 9
        }
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "person_new456",
        "firstName": "Jane",
        "lastName": "Doe",
        "fullName": "Jane Doe",
        "displayName": "Jane Doe",
        "email": "jane@doe.example",
        "title": "Operations Director",
        "linkedinUrl": "https://linkedin.com/in/janedoe",
        "status": "active",
        "customFields": { "shirt_size": "m", "nps": 9 },
        "createdAt": "2026-11-05T14:00:00Z",
        "updatedAt": "2026-11-05T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Update a person {{ tag: 'PATCH', label: '/v1/people/:id' }}

<Row>
  <Col>

    Partially update a person. Only the fields you send are changed, and any number of them can go in one request. Sending `firstName`/`lastName` recomputes `fullName` and `displayName`. In `customFields`, only the slugs you send change; send `null` to clear one. `companyIds` and `primaryCompanyId` are only read on create.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="PATCH" label="/v1/people/person_abc123">

    ```bash {{ title: 'cURL' }}
    curl -X PATCH https://api.weldsuite.org/v1/people/person_abc123 \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{ "title": "VP Operations", "customFields": { "nps": 10 } }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "person_abc123",
        "title": "VP Operations",
        "customFields": { "shirt_size": "m", "nps": 10 },
        "updatedAt": "2026-11-05T15:00:00Z"
      }
    }
    ```

  </Col>
</Row>
