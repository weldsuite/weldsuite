# Fiscal periods

Open / closed accounting periods. Mutations require the `fiscal_periods:write` scope; reads require `fiscal_periods:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Accounting entity scoping

Every fiscal period belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity.
- **On create:** send `entityId` in the JSON body. The external API does **not** pick a default for you. Read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## List fiscal periods {{ tag: 'GET', label: '/v1/fiscal-periods' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/fiscal-periods">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/fiscal-periods \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "fp_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create a fiscal period {{ tag: 'POST', label: '/v1/fiscal-periods' }}

<Row>
  <Col>

    Create a fiscal period.
    
    ### Accounting entity
    
    Include **`entityId`** (an `ent_*` id). The external API does not infer a default — resolve it from [accounting settings](/accounting-settings) (`defaultEntityId`) or [accounting entities](/accounting-entities) (`isDefault`).
    
    ### Required attributes
    
    <Properties>
      <Property name="name" type="string">Period name.</Property>
  <Property name="startDate" type="string">Start date.</Property>
  <Property name="endDate" type="string">End date.</Property>
    </Properties>
    
    Optional: `entityId`, `status`, `type`. Close and reopen actions are on the app API.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/fiscal-periods">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/fiscal-periods \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "name": "2024-Q4",
        "startDate": "2024-10-01",
        "endDate": "2024-12-31"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "fp_new456",
        "entityId": "ent_abc123",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Retrieve a fiscal period {{ tag: 'GET', label: '/v1/fiscal-periods/:id' }}

<Row>
  <Col>

    Retrieve a single fiscal period by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/fiscal-periods/fp_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/fiscal-periods/fp_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "fp_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>

<Row>

  </Col>

    ```bash {{ title: 'cURL' }}

      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{}'
    ```

    </CodeGroup>

        "id": "fp_abc123",

  </Col>
</Row>
