# Accounting entities

Legal entities in WeldBooks — each has its own chart of accounts, tax rates, and books. Reads require the `accounting_entities:read` scope. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Read-only resource

Accounting entities are read-only through the public API because a new entity needs its chart of accounts, tax rates and jurisdiction defaults set up, which only WeldBooks does. `POST`, `PUT`, `PATCH` and `DELETE` on `/v1/accounting-entities` answer `405 METHOD_NOT_ALLOWED`; make changes in WeldBooks.

---

## Multi-entity workspaces

An **accounting entity** is a legal company (a set of books) inside your workspace. Most WeldBooks resources — bills, invoices, bank accounts, tax rates, and so on — carry an `entityId` that points here.

Use this endpoint to list entities, read `isDefault`, and resolve ids to filter entity-scoped records. Workspace-wide defaults (including `defaultEntityId`) live on [accounting settings](/accounting-settings).

## The accounting entity model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `ent_abc123`).</Property>
  <Property name="name" type="string">Display name of the entity.</Property>
  <Property name="legalName" type="string">Registered legal name.</Property>
  <Property name="jurisdictionCode" type="string">ISO jurisdiction code (e.g. `NL`, `BE`).</Property>
  <Property name="baseCurrency" type="string">Functional currency (e.g. `EUR`).</Property>
  <Property name="locale" type="string">Locale for formatting (e.g. `nl-NL`).</Property>
  <Property name="isDefault" type="boolean">Whether this is the workspace default entity.</Property>
  <Property name="isActive" type="boolean">Whether the entity is active.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## List accounting entities {{ tag: 'GET', label: '/v1/accounting-entities' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/accounting-entities">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/accounting-entities \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>
