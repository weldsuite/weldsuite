# ICP declarations

Intracommunity supply declarations (NL ICP / EU B2B listings). Mutations require the `icp_declarations:write` scope; reads require `icp_declarations:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Accounting entity scoping

Every ICP declaration belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity.
- **On create:** send `entityId` in the JSON body. The external API does **not** pick a default for you. Read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## The ICP declaration model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `icp_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="periodStart" type="string">Declaration period start.</Property>
  <Property name="periodEnd" type="string">Declaration period end.</Property>
  <Property name="periodType" type="string">`monthly`, `quarterly`, or `yearly`.</Property>
  <Property name="status" type="string">Draft or filed.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## List icp declarations {{ tag: 'GET', label: '/v1/icp-declarations' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/icp-declarations">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/icp-declarations \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "icp_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create an ICP declaration {{ tag: 'POST', label: '/v1/icp-declarations' }}

<Row>
  <Col>

    Create an ICP declaration.
    
    ### Accounting entity
    
    Include **`entityId`** (an `ent_*` id). The external API does not infer a default — resolve it from [accounting settings](/accounting-settings) (`defaultEntityId`) or [accounting entities](/accounting-entities) (`isDefault`).
    
    ### Required attributes
    
    <Properties>
      <Property name="entityId" type="string">Accounting entity id.</Property>
  <Property name="periodStart" type="string">Period start date.</Property>
  <Property name="periodEnd" type="string">Period end date.</Property>
    </Properties>
    
    Optional: `periodType`, `periodLabel`, `status`. Calculate, file, and XML endpoints are on the app API.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/icp-declarations">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/icp-declarations \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "periodStart": "2024-01-01",
        "periodEnd": "2024-01-31",
        "periodType": "monthly"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "icp_new456",
        "entityId": "ent_abc123",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Retrieve an ICP declaration {{ tag: 'GET', label: '/v1/icp-declarations/:id' }}

<Row>
  <Col>

    Retrieve a single ICP declaration by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/icp-declarations/icp_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/icp-declarations/icp_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "icp_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>
