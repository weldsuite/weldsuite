# Bank accounts

Bank accounts linked to the general ledger. Mutations require the `bank_accounts:write` scope; reads require `bank_accounts:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## The bank account model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `ba_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="name" type="string">Account label.</Property>
  <Property name="iban" type="string">IBAN.</Property>
  <Property name="currency" type="string">Account currency.</Property>
  <Property name="glAccountId" type="string">Linked GL cash account.</Property>
  <Property name="isActive" type="boolean">Whether the account is active.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## Create a bank account {{ tag: 'POST', label: '/v1/bank-accounts' }}

<Row>
  <Col>

    Create a bank account.
    
    ### Required attributes
    
    <Properties>
      <Property name="name" type="string">Account name.</Property>
    </Properties>
    
    Optional: `entityId`, `bankName`, `iban`, `accountNumber`, `currency`, `glAccountId`, `isActive`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/bank-accounts">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/bank-accounts \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "name": "Operating account",
        "currency": "EUR"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "ba_new456",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>
