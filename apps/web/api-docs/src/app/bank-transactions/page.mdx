# Bank transactions

Imported or manual bank statement lines. Mutations require the `bank_transactions:write` scope; reads require `bank_transactions:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## The bank transaction model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `bt_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="bankAccountId" type="string">Parent bank account.</Property>
  <Property name="amount" type="string">Signed amount (decimal string).</Property>
  <Property name="currency" type="string">Transaction currency.</Property>
  <Property name="transactionDate" type="string">Value date.</Property>
  <Property name="description" type="string">Bank description / memo.</Property>
  <Property name="status" type="string">Reconciliation status.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## Create a bank transaction {{ tag: 'POST', label: '/v1/bank-transactions' }}

<Row>
  <Col>

    Create a bank transaction.
    
    Optional: `entityId`, `bankAccountId`, `amount`, `currency`, `transactionDate`, `reference`, `counterpartyName`. Import and reconcile flows are on the app API.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/bank-transactions">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/bank-transactions \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "bankAccountId": "ba_abc123",
        "amount": "-45.00",
        "currency": "EUR"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "bt_new456",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>
