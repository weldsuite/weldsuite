# Accounting documents

Scanned receipts, statements, and other supporting files. Reads require the `accounting_documents:read` scope. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Read-only resource

Accounting documents are read-only through the public API because the document inbox (OCR, vendor matching, linking to bills and invoices) runs in WeldBooks, and the public API has no way to upload the file a document points at. `POST`, `PUT`, `PATCH` and `DELETE` on `/v1/accounting-documents` answer `405 METHOD_NOT_ALLOWED`; make changes in WeldBooks.

---

## Accounting entity scoping

Every accounting document belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity. To find the id, read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## The accounting document model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `doc_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>

  <Property name="updatedAt" type="timestamp">When last updated.</Property>

## List accounting documents {{ tag: 'GET', label: '/v1/accounting-documents' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/accounting-documents">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/accounting-documents \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "doc_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Retrieve an accounting document {{ tag: 'GET', label: '/v1/accounting-documents/:id' }}

<Row>
  <Col>

    Retrieve a single accounting document by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/accounting-documents/doc_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/accounting-documents/doc_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "doc_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>
