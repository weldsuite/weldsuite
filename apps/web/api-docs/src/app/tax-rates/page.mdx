# Tax rates

VAT / GST rate definitions per entity. Mutations require the `tax_rates:write` scope; reads require `tax_rates:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Accounting entity scoping

Every tax rate belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity.
- **On create:** send `entityId` in the JSON body. The external API does **not** pick a default for you. Read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## The tax rate model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `txr_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>

  <Property name="rate" type="string">Percentage as decimal string.</Property>
  <Property name="jurisdictionCode" type="string">Jurisdiction code.</Property>
  <Property name="isActive" type="boolean">Whether the rate is active.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## List tax rates {{ tag: 'GET', label: '/v1/tax-rates' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/tax-rates">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/tax-rates \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "txr_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Create a tax rate {{ tag: 'POST', label: '/v1/tax-rates' }}

<Row>
  <Col>

    Create a tax rate.
    
    ### Accounting entity
    
    Include **`entityId`** (an `ent_*` id). The external API does not infer a default — resolve it from [accounting settings](/accounting-settings) (`defaultEntityId`) or [accounting entities](/accounting-entities) (`isDefault`).
    
    ### Required attributes
    
    <Properties>
      <Property name="name" type="string">Rate name.</Property>
  <Property name="rate" type="string | number">Rate percentage.</Property>
    </Properties>
    
    Optional: `entityId`, `jurisdiction` / `jurisdictionCode`, `isActive`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/tax-rates">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/tax-rates \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "name": "21% BTW",
        "rate": 21,
        "jurisdiction": "NL"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "txr_new456",
        "entityId": "ent_abc123",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>

## Retrieve a tax rate {{ tag: 'GET', label: '/v1/tax-rates/:id' }}

<Row>
  <Col>

    Retrieve a single tax rate by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/tax-rates/txr_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/tax-rates/txr_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "txr_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>
