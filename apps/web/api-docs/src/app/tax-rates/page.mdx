# Tax rates

VAT / GST rate definitions per entity. Mutations require the `tax_rates:write` scope; reads require `tax_rates:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## The tax rate model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `txr_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="name" type="string">Rate label (e.g. "21% BTW").</Property>
  <Property name="rate" type="string">Percentage as decimal string.</Property>
  <Property name="jurisdictionCode" type="string">Jurisdiction code.</Property>
  <Property name="isActive" type="boolean">Whether the rate is active.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## Create a tax rate {{ tag: 'POST', label: '/v1/tax-rates' }}

<Row>
  <Col>

    Create a tax rate.
    
    ### Required attributes
    
    <Properties>
      <Property name="name" type="string">Rate name.</Property>
  <Property name="rate" type="string | number">Rate percentage.</Property>
    </Properties>
    
    Optional: `entityId`, `jurisdiction` / `jurisdictionCode`, `isActive`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/tax-rates">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/tax-rates \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "name": "21% BTW",
        "rate": 21,
        "jurisdiction": "NL"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "txr_new456",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>
