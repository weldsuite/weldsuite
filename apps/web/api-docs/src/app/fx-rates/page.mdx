# FX rates

Exchange rates for multi-currency bookkeeping. Mutations require the `fx_rates:write` scope; reads require `fx_rates:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## The FX rate model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `fx_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="fromCurrency" type="string">Source currency.</Property>
  <Property name="toCurrency" type="string">Target currency.</Property>
  <Property name="rate" type="string">Exchange rate (decimal string).</Property>
  <Property name="effectiveDate" type="string">Date the rate applies.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## Create a FX rate {{ tag: 'POST', label: '/v1/fx-rates' }}

<Row>
  <Col>

    Create a FX rate.
    
    Optional: `entityId`, `fromCurrency`, `toCurrency`, `rate`, `effectiveDate`, `source`.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/fx-rates">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/fx-rates \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "fromCurrency": "USD",
        "toCurrency": "EUR",
        "rate": "0.92"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "fx_new456",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```

  </Col>
</Row>
