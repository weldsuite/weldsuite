# Reconciliation rules

Rules that auto-match bank transactions to ledger entries. Reads require the `reconciliation_rules:read` scope. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## Read-only resource

Reconciliation rules are read-only through the public API because rules decide which ledger and tax accounts bank lines are posted to, and WeldBooks validates them. `POST`, `PUT`, `PATCH` and `DELETE` on `/v1/reconciliation-rules` answer `405 METHOD_NOT_ALLOWED`; make changes in WeldBooks.

---

## Accounting entity scoping

Every reconciliation rule belongs to one **accounting entity** (legal company / set of books). The `entityId` field on each record references an [accounting entity](/accounting-entities) (`ent_*`).

- **On read:** responses include `entityId` — that is how you know which books a record belongs to.
- **On list:** pass `?entityId=ent_abc123` to restrict results to one entity. To find the id, read `defaultEntityId` from [accounting settings](/accounting-settings), or list [accounting entities](/accounting-entities) and use the row with `isDefault: true`.

## List reconciliation rules {{ tag: 'GET', label: '/v1/reconciliation-rules' }}

<Row>
  <Col>

    Retrieve a cursor-paginated list. All list endpoints accept the query parameters below. See [Pagination](/pagination) for cursor semantics.

    ### Query parameters

    <Properties>
      <Property name="limit" type="integer">Number of items to return. Minimum 1, maximum 200. Defaults to a server-side value (typically 25). See [Pagination](/pagination).</Property>
      <Property name="cursor" type="string">Opaque cursor from `pagination.cursor` on the previous page. Omit for the first page.</Property>
      <Property name="entityId" type="string">Filter to records belonging to one accounting entity (`ent_*`). Omit to list across all entities in the workspace.</Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/reconciliation-rules">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.weldsuite.org/v1/reconciliation-rules \
      -H "Authorization: Bearer wsk_your_api_key" \
      -d entityId=ent_abc123 \
      -d limit=25
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": [
        { "id": "rr_abc123", "entityId": "ent_abc123" }
      ],
      "pagination": { "totalCount": 1, "hasMore": false, "cursor": null }
    }
    ```

  </Col>
</Row>

## Retrieve a reconciliation rule {{ tag: 'GET', label: '/v1/reconciliation-rules/:id' }}

<Row>
  <Col>

    Retrieve a single reconciliation rule by ID. The response includes `entityId` so you can tell which accounting entity owns the record.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/reconciliation-rules/rr_abc123">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/reconciliation-rules/rr_abc123 \
      -H "Authorization: Bearer wsk_your_api_key"
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "rr_abc123",
        "entityId": "ent_abc123"
      }
    }
    ```

  </Col>
</Row>
