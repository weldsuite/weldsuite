# Reconciliation rules

Rules that auto-match bank transactions to ledger entries. Mutations require the `reconciliation_rules:write` scope; reads require `reconciliation_rules:read`. {{ className: 'lead' }}

<ResourceVersionBanner />

---

## The reconciliation rule model

### Properties

<Properties>
  <Property name="id" type="string">Unique identifier (e.g. `rr_abc123`).</Property>
  <Property name="entityId" type="string">Owning accounting entity.</Property>
  <Property name="name" type="string">Rule name.</Property>
  <Property name="priority" type="number">Evaluation order.</Property>
  <Property name="isActive" type="boolean">Whether the rule is active.</Property>
  <Property name="createdAt" type="timestamp">When created.</Property>
  <Property name="updatedAt" type="timestamp">When last updated.</Property>
</Properties>

## Create a reconciliation rule {{ tag: 'POST', label: '/v1/reconciliation-rules' }}

<Row>
  <Col>

    Create a reconciliation rule.
    
    Optional: `entityId`, `name`, `matchCriteria`, `actions` (passthrough JSON).

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/reconciliation-rules">

    ```bash {{ title: 'cURL' }}
    curl https://api.weldsuite.org/v1/reconciliation-rules \
      -H "Authorization: Bearer wsk_your_api_key" \
      -H "Content-Type: application/json" \
      -d '{
        "entityId": "ent_abc123",
        "name": "Match supplier payments"
      }'
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "data": {
        "id": "rr_new456",
        "createdAt": "2024-12-01T14:00:00Z",
        "updatedAt": "2024-12-01T14:00:00Z"
      }
    }
    ```
