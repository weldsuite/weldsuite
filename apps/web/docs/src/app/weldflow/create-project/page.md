Set up a shared project space for tasks, timelines, and files. {% .lead %}

---

## Create the project

1. Open **WeldFlow**.
2. Click **New project** (or **+** next to Projects in the sidebar).
3. Enter a **name** and optional **description**.
4. Choose a **template** if your workspace offers one (blank, software, marketing, etc.).
5. Save.

The project opens with default views: Tasks, and optionally Gantt, Files, or Goals depending on template.

---

## Add members

1. Open the project.
2. Go to **Members** or **Settings** within the project.
3. Invite workspace teammates by name or email.
4. Set their role (member, admin) if roles are enabled.

Members see the project in their WeldFlow sidebar.

---

## Add tasks

1. Open the **Tasks** view.
2. Click **New task** or add a row in list view / card in board view.
3. Set title, assignee, due date, and status.
4. Group tasks with **sections** or **labels** if your template supports them.

Switch to **Gantt** to set start/end dates and dependencies for timeline planning.

---

## Project chat

Many projects include a **Chat** panel on the right — use it for updates tied to the project without switching to WeldChat.
