Set up a shared project space for tasks, timelines, and files. {% .lead %}

---

## Create the project

1. Open **WeldFlow**.
2. Hover **Projects** in the sidebar and click **+** (or click **Add project** when the list is empty).
3. Enter a **name** for the project.
4. Optionally pick a **color** and **icon** so the project is easy to spot in the sidebar.
5. Click **Create Project**.
6. Click the new project in the sidebar to open it.

{% video src="/videos/help/weldflow-create-project.mp4" poster="/videos/help/weldflow-create-project.jpg" title="How to create a project in WeldFlow" caption="Add a project from the sidebar, give it a name and color, then open it." /%}

The project opens on its **Tasks** view. The tabs next to it (Gantt, Sheets, Whiteboard, Workload, Files, and more) give you other ways to plan and share the work.

---

## Add members

1. Open the project.
2. Go to **Members** or **Settings** within the project.
3. Invite workspace teammates by name or email.
4. Set their role (member, admin) if roles are enabled.

Members see the project in their WeldFlow sidebar.

---

## Add tasks

1. Open the **Tasks** view.
2. Click **New task** or add a row in list view / card in board view.
3. Set title, assignee, due date, and status.
4. Group tasks with **sections** or **labels** if your template supports them.

Switch to **Gantt** to set start/end dates and dependencies for timeline planning.

---

## Project chat

Many projects include a **Chat** panel on the right — use it for updates tied to the project without switching to WeldChat.
