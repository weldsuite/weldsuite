Register a new domain name directly in WeldHost when you want WeldSuite to manage registration and DNS together. {% .lead %}

---

## Search for a domain

1. Open **WeldHost** in the app rail.
2. Go to **Register Domain** in the module sidebar.
3. Enter the name you want (for example `yourcompany`).
4. Pick a TLD (`.com`, `.io`, and others shown in results).
5. Review availability and pricing.

Results show whether each name is available, taken, or premium.

---

## Complete registration

1. Select an available domain and click to continue.
2. Confirm registrant contact details (required by domain registries).
3. Choose add-ons if offered (privacy protection, auto-renew).
4. Complete checkout.

After payment, the domain appears in **My Domains** with status **Pending** until registration finishes, then **Active**.

---

## After registration

- **DNS** — records are ready in the domain panel once the zone is active. See [Add DNS records](/weldhost/manage-dns-records).
- **Auto-renew** — enable in the domain **Settings** tab so the name does not expire unexpectedly.
- **Email** — point WeldMail at this domain after MX records are set (often created automatically when you enable mail).

{% callout title="Already own the domain?" %}
Use [Connect external domain](/weldhost/connect-external-domain) instead of registering again.
{% /callout %}
