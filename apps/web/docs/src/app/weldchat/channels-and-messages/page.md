Send messages, organize conversations, and start calls from WeldChat. {% .lead %}

---

## Join a channel

1. Open **WeldChat** from the app rail.
2. Browse **Channels** in the sidebar.
3. Click a channel name to open its message history.

If you do not see a channel, use **Browse channels** or ask an admin to invite you to private channels.

---

## Send a message

1. Select a channel or DM.
2. Type in the message box at the bottom.
3. Press **Enter** to send (or **Shift+Enter** for a new line, depending on your settings).

Attach files with the **+** menu, mention teammates with `@`, and add emoji reactions to existing messages.

---

## Use threads

1. Hover a message and choose **Reply in thread**.
2. Write your reply in the thread panel.
3. Thread replies stay linked to the original message so the main channel stays readable.

---

## Direct messages

1. Click **DMs** or the **+** next to Direct Messages.
2. Search for a teammate.
3. Start chatting — same features as channels, plus **voice/video call** buttons in the header.

---

## Start a call

From an open DM or channel header, click the **phone** or **video** icon. Other participants receive a notification to join.

---

## Stay organized

- **Pin** important messages for the channel.
- **Bookmark** messages you need later under **Saved**.
- **Mute** noisy channels from the channel menu.
