Connect your mailbox so messages sync into WeldMail. {% .lead %}

{% callout title="Admin setup" %}
Workspace admins enable WeldMail and allowed providers under **Settings → WeldMail** before users can connect. If you do not see connect options, ask an admin.
{% /callout %}

---

## Connect your mailbox

1. Open **Settings** from the app rail (or your profile menu).
2. Go to **WeldMail** (or **Email accounts**).
3. Click **Add account** or **Connect Gmail / Microsoft**.
4. Sign in with the provider and approve access when prompted.
5. Wait for the initial sync — recent mail appears in **WeldMail → Inbox**.

Repeat for additional accounts if your workspace allows multiple connections per user.

---

## Choose default send address

If you connected more than one account:

1. Open **WeldMail**.
2. Use the account switcher in the sidebar or header.
3. Set which address **new messages** send from in settings or the compose window.

---

## Troubleshooting

| Issue | What to try |
| --- | --- |
| OAuth window closes without connecting | Retry; ensure pop-ups are allowed |
| Old mail missing | Sync may be limited to recent months — check admin sync settings |
| Send fails | Verify the account is still connected in Settings |
