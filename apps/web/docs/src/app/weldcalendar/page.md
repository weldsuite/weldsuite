WeldCalendar keeps schedules in one place — personal events, shared team calendars, and public booking links. {% .lead %}

---

## What you can do

- View **day, week, and month** layouts
- Create and edit **events** with location, guests, and reminders
- Connect **Google Calendar** for two-way sync
- Publish **booking pages** so external people pick a time slot
- Toggle multiple calendars from the sidebar

A mini-calendar in the sidebar helps jump to dates quickly.
