Themes set how your forms look, and every form picks one. {% .lead %}

---

## Pick a theme

1. Open the form and go to the **Design** tab.
2. Choose a theme from the list. The preview updates at once.
3. Click **Edit** to adjust it, or create a new one.

{% figure src="/images/help/weldforms-design.png" alt="The Design tab with the theme list and a live preview" caption="Pick a theme and see the form change at once." /%}

## What a theme controls

- **Fonts** for questions and answers
- **Colours** for text, buttons, answers and the background
- **Background** colour or image
- **Button and field style**
- **Logo**

A theme belongs to the workspace, so every form that uses it changes when you edit it. Duplicate a theme first if you only want to change one form. Workspace admins manage the full list in **WeldForms** > **Settings**, together with defaults and workspace templates.

## Text in the form

The buttons and hints WeldForms adds itself (Next, Submit, "press Enter", validation messages) appear in the form's language: English or Dutch. Your own questions are shown exactly as you write them, in any language.
