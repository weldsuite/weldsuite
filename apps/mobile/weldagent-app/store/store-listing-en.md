## Full description (both, max 4000 chars)
WeldAgent is the mobile companion for WeldSuite AI agents. Chat with your personal assistant or a named workspace agent, review run history, and keep an eye on remaining AI credits.

Built for operators who need an agent in their pocket: start a conversation, grant the tools an agent needs, and get a push when a run finishes or a reply is ready.

FEATURES
- Home dashboard with credits, recent chats, and recent agent runs
- Workspace agents: create, activate, pause, delete, and run now
- Chat threads with WeldAgent or a bound workspace agent
- Activity feed of runs across agents
- Push notifications when a run completes or a chat reply is ready
- Credits balance with a path to top up on the web (no in-app purchase)
- Light and dark mode
- Secure sign-in with your WeldSuite account (Clerk-powered authentication)
- Enterprise workspace support

REQUIREMENTS
- An active WeldSuite workspace (sign up at weldsuite.com)
- AI credits on the workspace wallet for chat and agent runs

WeldAgent is the mobile-first extension of the WeldSuite platform. Conversations and agent configuration stay in sync with the web app at app.weldsuite.org.
