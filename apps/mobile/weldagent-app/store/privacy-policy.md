# Privacy Policy

The live privacy policy is published at **https://weldsuite.org/privacy** and covers all WeldSuite products, including WeldAgent.

Both the iOS App Store and Google Play require a URL to a hosted privacy policy. Use `https://weldsuite.org/privacy` in both consoles.

## Data disclosure summary (used to fill store forms)

**Data collected and why:**
- **Email, name, user ID**, for account sign-in and identifying who started a chat or agent run
- **Device push token**, to deliver push notifications when an agent run finishes or a chat reply is ready
- **App usage events** (screen views), anonymized, used for product analytics
- **Crash diagnostics**, to fix bugs
- **Chat messages and agent instructions**, stored in the workspace tenant database so conversations persist across devices

**Not collected:** location, financial data (this app does not process payments), contacts, photos, browsing history, health data, SMS.

**Data sharing:** None with third parties for advertising. Authentication data is processed by Clerk; push notifications are delivered via Apple APNs and Google FCM. AI generation is processed through the WeldSuite AI gateway. See the full policy for provider list.

**Retention & deletion:** Account data is retained while the account is active. Users can request deletion via https://weldsuite.com/support.
